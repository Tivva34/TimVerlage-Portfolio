# My Portfolio

This is my personal portfolio website built with React and Vite. It showcases who I am, the projects I've worked on, the technologies I use, and provides a way to contact me.

The goal of this project was to create a modern, responsive portfolio while improving my React skills and learning how to structure larger applications.

## Live Demo

🔗 https://tivva34.github.io/TimVerlage-Portfolio/

## Built With

- React
- Vite
- JavaScript (ES6+)
- HTML5
- CSS3
- Framer Motion
- Formspree
- GitHub Pages

## Features

- Responsive design for desktop, tablet and mobile
- Animated hero section
- Project showcase with GitHub integration
- Dynamic language icons for projects
- Contact form using Formspree
- Accessible navigation and semantic HTML
- Component-based architecture

## Project Structure

```
src/
│
├── components/
├── data/
├── hooks/
├── styles/
└── assets/
```

The project has been refactored to separate:

- Components
- Styles
- Static data
- Custom React hooks

to make the code easier to maintain.

## Installation

Clone the repository

```bash
git clone https://github.com/Tivva34/TimVerlage-Portfolio.git
```

Go into the project

```bash
cd TimVerlage-Portfolio
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

## Build

Create a production build

```bash
npm run build
```

Deploy to GitHub Pages

```bash
npm run deploy
```
